umbral_dff   <- 2 * sqrt((p + 1) / n)    # DFFITS: 2√((p+1)/n)

# ── Detección ────────────────────────────────────────────────────────────────

flag_lev  <- lev   > umbral_lev

9.2.1 A6. Comparación formal de modelos candidatos (AIC/BIC)

Los criterios de información de Akaike y Bayesiano de Schwarz permiten cotejar modelos con distinto número de parámetros penalizando la complejidad (Akaike, 1974; Schwarz, 1978):

\[AIC = n\ln(2\pi\hat{\sigma}^2) + n + 2(p+2), \qquad BIC = n\ln(2\pi\hat{\sigma}^2) + n + (p+2)\ln(n)\]

donde \(\hat{\sigma}^2 = SSE/n\) es el estimador de máxima verosimilitud de la varianza del error y \(p + 2\) es el número de parámetros del modelo gaussiano (intercepto, \(p\) pendientes y varianza). Estas fórmulas coinciden con las calculadas por la función AIC() de R. Convencionalmente, una diferencia \(\Delta AIC > 2\) se interpreta como evidencia sustancial a favor del modelo con menor AIC; \(\Delta AIC > 10\) como evidencia fuerte (Burnham y Anderson, 2002).

9.2.2 A7. Validación cruzada \(k\)-fold y tamaño del efecto

La validación cruzada con \(k\) pliegues particiona aleatoriamente el conjunto de datos en \(k\) subconjuntos \(F_1, \ldots, F_k\) de tamaño aproximadamente igual. En cada iteración \(j = 1, \ldots, k\), el modelo se ajusta con los \(k-1\) pliegues restantes y se evalúa sobre \(F_j\), garantizando que cada observación sea predicha exactamente una vez fuera de muestra. Sea \(\hat{G3}_i^{(-F_j)}\) la predicción de la observación \(i \in F_j\) con el modelo ajustado sin las observaciones de \(F_j\). La métrica de error fuera de muestra agregada es:

\[RMSE_{CV} = \sqrt{\frac{1}{n}\sum_{j=1}^{k}\sum_{i \in F_j}\bigl(G3_i - \hat{G3}_i^{(-F_j)}\bigr)^2}\]

Se adopta \(k = 10\), valor estándar que ofrece un buen compromiso sesgo-varianza del estimador del error de generalización (Hastie, Tibshirani y Friedman, 2009, Cap. 7). Para \(n\) grande y \(k = 10\), los valores de \(RMSE_{CV}^{(k)}\) y de su análogo Leave-One-Out (\(k = n\)) son numéricamente próximos.

Para el modelo MAT con predictor G2, \(RMSE_{CV} = 0.8389\) frente a un \(RMSE\) dentro de muestra de \(0.8384\): la diferencia de 0.0005 puntos es prácticamente nula, lo que confirma la ausencia de sobreajuste. En POR, la diferencia es de \(-0.0174\) puntos, prácticamente nula, lo que confirma la ausencia de sobreajuste. Los valores de \(R^2_{CV} = 0.9365\) (MAT) y \(0.8743\) (POR) son consistentes con los \(R^2\) dentro de muestra, lo cual respalda que la capacidad predictiva se mantiene fuera de muestra.

Para cuantificar la magnitud estandarizada del efecto, se emplea el estadístico \(f^2\) de Cohen (1988, Cap. 9):

\[f^2 = \frac{R^2}{1 - R^2}\]

con las convenciones estándar (Cohen 1988, §9.2.1): \(0.02 \leq f^2 < 0.15\) (pequeño), \(0.15 \leq f^2 < 0.35\) (mediano), \(f^2 \geq 0.35\) (grande); \(f^2 < 0.02\) se considera trivial.

9.2.3 A8. Análisis formal de robustez ante influyentes

En la Sección 5.4 se identificaron las observaciones influyentes y se computaron los cambios relativos en \(\hat{\beta}_1\). Aquí se formaliza la decisión estadística mediante una prueba directa sobre la diferencia entre los coeficientes estimados con y sin influyentes. Sean \(\hat{\beta}_1^{\text{full}}\) y \(\hat{\beta}_1^{\text{si}}\) las pendientes estimadas con el conjunto completo y sin las observaciones flagueadas, con errores estándar \(SE_{\text{full}}\) y \(SE_{\text{si}}\). Bajo \(H_0: \beta_1^{\text{full}} = \beta_1^{\text{si}}\), asumiendo independencia aproximada entre las dos estimaciones (los conjuntos comparten la mayoría de observaciones, por lo que esta es una cota conservadora), el estadístico

\[z = \frac{\hat{\beta}_1^{\text{full}} - \hat{\beta}_1^{\text{si}}}{\sqrt{SE_{\text{full}}^2 + SE_{\text{si}}^2}}\]

se distribuye aproximadamente \(\mathcal{N}(0, 1)\). Se rechaza \(H_0\) al \(\alpha = 0.05\) si \(|z| > 1.96\). Como criterio cuantitativo complementario, se exige adicionalmente \(|\Delta\hat{\beta}_1| < 5\%\) para considerar el modelo prácticamente robusto.

Nota sobre el criterio de solapamiento de IC. Como criterio gráfico podría compararse el solapamiento de los IC al 95%, pero dos IC al 95% que se solapan no son equivalentes a no rechazar \(H_0\) al \(\alpha = 0.05\) (Schenker y Gentleman, 2001, The American Statistician, 55: 182–186); el equivalente formal requeriría IC al \(\approx 83.4\%\) (Cumming y Finch, 2005). Por ello, la decisión formal se apoya en el estadístico \(z\) y en el cambio relativo \(|\Delta\hat{\beta}_1|\), no en la inspección de solapamiento.

Dataset β̂₁ (completo) β̂₁ (sin infl.) Δβ̂₁ (%) Estadístico z p-valor Decisión (α=0.05)

En MAT, \(z = -0.1305\) (\(p = 0.8961\)); en POR, \(z = -0.2979\) (\(p = 0.7658\)). En ambos casos no se rechaza \(H_0\) al \(\alpha = 0.05\), y \(|\Delta\hat{\beta}_1| < 1\%\) confirma que la diferencia tampoco es prácticamente relevante. Decisión formal: se conserva el modelo ajustado con el conjunto completo de observaciones; las observaciones influyentes no alteran de manera estadística ni prácticamente significativa los estimadores.

9.2.4 A9. Errores estándar robustos a heterocedasticidad (HC3)

Dado que el diagnóstico de la Sección 4.2 detectó heterocedasticidad en MAT (Breusch-Pagan, \(p < 0.001\)), los errores estándar clásicos de MCO pueden estar sesgados. Como verificación adicional de robustez, se recalculan los IC para \(\hat{\beta}_1\) con el estimador HC3 de White (1980), implementado en sandwich::vcovHC. El HC3 es preferible al HC1 en muestras finitas por su mejor comportamiento frente a observaciones de alto apalancamiento (Long y Ervin, 2000).

9.2.5 A10. Cobertura empírica de los intervalos de predicción

La inferencia clásica sobre \(\hat{\beta}_j\) está protegida asintóticamente por el TCL aun bajo desviaciones moderadas de la normalidad de \(\varepsilon\). Sin embargo, la cobertura nominal del 95 % de los intervalos de predicción individuales (IP) reportados en §2.6 y §3.5 sí depende directamente de que \(\varepsilon \sim \mathcal{N}(0, \sigma^2)\), ya que la fórmula

\[\hat{Y}_0 \pm t_{\alpha/2,\, n-2}\hat{\sigma}\sqrt{1 + \tfrac{1}{n} + \tfrac{(x_0 - \bar{x})^2}{S_{xx}}}\]

emplea cuantiles \(t\) que solo son exactos bajo errores gaussianos. Dado que en §4.2 y §4.3 las pruebas de normalidad rechazaron \(H_0\), evaluamos empíricamente la cobertura efectiva de los IP construidos por bootstrap no paramétrico de pares (Davison y Hinkley, 1997, §6.3).

# Cobertura empírica de IP al 95% para una observación nueva en x0 = mediana(G2)
# Bootstrap no paramétrico de pares (G2, G3) — Davison y Hinkley (1997, §6.3)
set.seed(42)
B <- 2000

cobertura_ip_boot <- function(datos, x0, B = 2000, nivel = 0.95) {
  n     <- nrow(datos)
  cubre <- logical(B)
  for (b in 1:B) {
    idx_b   <- sample.int(n, n, replace = TRUE)
    datos_b <- datos[idx_b, ]
    mod_b   <- lm(G3 ~ G2, data = datos_b)
    ip_b    <- predict(mod_b, newdata = data.frame(G2 = x0),
                       interval = "prediction", level = nivel)
    candidatos <- datos$G3[abs(datos$G2 - x0) <= 1]
    if (length(candidatos) == 0) candidatos <- datos$G3
    y_nuevo   <- sample(candidatos, 1)
    cubre[b]  <- (y_nuevo >= ip_b[, "lwr"]) & (y_nuevo <= ip_b[, "upr"])
  }
  mean(cubre)
}

cob_mat_g12 <- cobertura_ip_boot(mat, x0 = 12, B = B)
cob_por_g12 <- cobertura_ip_boot(por, x0 = 12, B = B)

Una brecha cercana a 0 indica que la cobertura efectiva coincide con la nominal pese al rechazo de normalidad.
